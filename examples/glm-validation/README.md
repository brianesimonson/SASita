# PROC GLM validation — Sassy v0.4.11, helper revision 2

Upload only 01-sas-glm-comparison.sas to SAS Studio, open it and run the entire program. No folder edits or CSV uploads are needed: Sassy results are embedded with explicit types and full double precision. Download the SAS HTML Results and Log and return both.

Two models cover the manual’s unbalanced 2×2 example and an unbalanced 3×2 design with a numeric covariate, CLASS interaction and class-by-covariate interaction. Compare OverallANOVA, Type I/III ModelANOVA, SOLUTION estimates/SE/t/p, fit statistics, predictions and residuals. Statistics use relative criterion 1e-10; the modest-scale prediction/residual fixture uses absolute criterion 1e-12, including near-zero residuals. These thresholds are not a promise of fixed decimal places or bit identity. Missing tables/columns are explicit errors, not passes. Label casing/multiple spaces are normalized; A*X is mapped to X*A explicitly for these fixture models. This checks numbers without claiming actual app labels already match SAS. Special SAS missing codes are normalized to ordinary missing for value comparisons. SAS CV is mapped to coeffvar when present; unknown fields still fail and print descriptors. Exact special-missing codes are not certified. B flags, labels/formats/lengths and all ODS descriptors are not certified by these numeric checks.

The other SAS model files run in Sassy too; CSVs archive the expected results but are not needed for the SAS comparison. Models are deterministic and do not depend on random stream agreement. Actual SAS results for the first helper confirm the matched calculations, but expose label, special-missing and near-zero comparison issues, plus absent fit checks. The uploaded log identifies a missing coeffvar column. This helper addresses those checks; this newly generated program has not yet run in SAS.
